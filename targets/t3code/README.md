# T3 Code

Two importable T3 Code theme files. Each file includes both light and dark
appearances; the Vivid theme is a separate choice in the theme picker.

## Install

In the macOS desktop app, open **Settings → Appearance → Import theme** and
select `grafana.json` or `grafana-vivid.json`. The imported theme appears in
the theme list. Its light and dark palettes follow the app's selected
appearance mode.

## Files

- `grafana.json` — Grafana, using the default dim flavor
- `grafana-vivid.json` — Grafana Vivid, using the vivid flavor

These files use T3 Code's ThemeFile v1 format and are generated from
[`../../palette.toml`](../../palette.toml). Do not edit them by hand.
