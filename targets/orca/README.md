# Grafana for Orca IDE

Grafana Dark, Light, Dark Dim and Light Dim cover the app, code editor and
integrated terminal. The terminal themes include all 16 ANSI colors.

## Install

With Orca Desktop 1.4.246 or later running and plugins enabled, run this from
the repository root on the desktop host:

```sh
orca plugin install ./targets/orca
```

1. In **Settings → Appearance**, choose **Grafana Light** and **Grafana Dark**
   in the light and dark app theme pickers. The editor follows the app theme
   by default. You can also select the matching light and dark editor themes
   independently.
2. In **Settings → Terminal**, choose **Grafana Dark** as the terminal theme.
   Enable a separate light theme and choose **Grafana Light** if you switch
   between appearances.

Choose the corresponding **Dim** variants for softer colors. The plugin
contains only theme data and requires no code permissions. Orca Desktop loads
the plugin. Headless `orca serve` has no plugin installer.

## Chat appearance

With the app theme selected, chat bubbles, inline code and fenced code blocks
use Grafana surfaces. In dark mode Orca lightens the chat canvas slightly.
For the exact Grafana Dark background (`#171717`), select **Grafana Dark**
as the terminal theme and turn on **Match terminal interface** in
**Settings → Chat UI → Appearance**. This also applies the terminal font and
lets Orca derive the other chat colors from the terminal palette.

Chat code fences use Orca's built-in Light+ and Dark+ syntax colors.
Grafana's syntax colors apply to the code editor.

The JSON files are generated by `tools/generate.py` from `palette.toml`.
Edit the palette or emitter to change them.
