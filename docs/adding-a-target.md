# Adding a target

Three steps. Nothing else in the repo needs to know how many targets exist.

## 1. Write the emitter

`tools/gcs/emit/<slug>.py`, exporting one function:

```python
def emit(p: Palette) -> dict[str, str]:
    """{path relative to targets/<slug>/: file contents}"""
```

Returning a dict is what makes `--check`, orphan detection and multi-file
targets work without special cases.

**The emitter must not touch the filesystem.** `tools/generate.py` is the
only writer. Keeping that invariant is what lets the emitters stay readable
as the registry grows.

Rules the generator enforces or relies on:

- Every file ends with **exactly one** trailing newline. `generate.py`
  raises if not, because `--check` would otherwise flap.
- JSON is `json.dumps(obj, indent=2, ensure_ascii=False, sort_keys=False)`,
  pinned so a Python upgrade cannot reshuffle key order into a phantom diff.
- Where the format supports comments, start the file with
  `Generated by tools/generate.py from palette.toml. Do not edit.` Where it
  does not — JSON, plist — put that line in the target's README instead.
  Do **not** add an unknown key to carry it; Chrome, for one, warns about
  unrecognized manifest keys.

### What the palette gives you

```python
for name, v in p.each():        # ("dark", Variant), ("light", Variant)
    v.id                        # "grafana-dark"
    v.label                     # "Grafana Dark"
    v.appearance                # "dark" | "light"
    v.is_dark                   # bool

    v.surfaces["base"]          # "#1e1e1e"
    v.text["fg"]                # "#c9c9c9"
    v.accents["orange"]         # "#e47534"

    v.rc("keyword")             # role color, "#e47534"
    v.role("comment").italic    # True
    v.diagnostic["error"].color
    v.diff["added"].color

    v.color("accents.pink")     # resolve any dotted reference
    v.ansi("dim")[9]            # ANSI slot, "dim" | "vivid"
    v.terminal["cursor_bg"]

    v.contrast_on_base(hexv)    # WCAG ratio, if you need to decide something
```

Prefer `v.rc("role")` over `v.accents["colour"]`. Roles are the layer users
retune; reaching past them into raw colors means a role change silently
skips your target.

For conversions, `gcs.color` has `to_floats` (iTerm2 plists),
`to_rgb_list` (Chrome manifests), `contrast`, `mix` and `delta_e`.

## 2. Register it

One line in `tools/gcs/registry.py`:

```python
Target(
    slug="alacritty",
    display="Alacritty",
    emit=alacritty.emit,
    artifacts="2 TOML files",
    install="copy into ~/.config/alacritty/ and import it",
    upstream="https://alacritty.org/config-alacritty.html",
    flavors=True,   # only if it also ships -vivid files
),
```

`artifacts` and `install` feed the README install matrix, which is a
generated block — so registering the target updates the docs.

## 3. Write the install notes and generate

`targets/<slug>/README.md`, hand-written. Install prose is where a human
beats a template, and it changes on the tool's schedule rather than the
palette's, so `--check` ignores it.

```sh
python3 tools/generate.py --target <slug>   # just yours, while iterating
python3 tools/generate.py                   # everything, including doc tables
python3 tools/generate.py --check           # confirm it round-trips
```

## Conventions worth following

**Shape the directory the way the tool expects.** `targets/vim` works as a
`runtimepath` entry, `targets/vscode` as an extension root,
`targets/wezterm/colors/` as a `color_scheme_dirs` entry. Someone should be
able to symlink your subtree straight into place.

**Name files `<variant-id>.<ext>`** — `grafana-dark.toml`, not
`dark.toml`. Several tools derive the user-visible name from the filename
(iTerm2 presets and WezTerm schemes both do), and a bare `dark` is useless
in a list of thirty themes.

**Flavors suffix, dim does not.** `grafana-dark.toml` is the dim flavor;
`grafana-dark-vivid.toml` is vivid. Read `p.scheme["default_flavor"]` rather
than hardcoding which one is bare.

**Terminal targets should consume `v.ansi(flavor)`** rather than picking
accents themselves. That table is shared across seven targets on purpose; a
target that invents its own mapping will drift.
